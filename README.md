# 🌸 Desert Flower - Fresh Flower E-Commerce System

## 📌 Product Description

Desert Flower là hệ thống website bán hoa tươi hiện đại được phát triển nhằm tối ưu toàn bộ quy trình kinh doanh hoa online từ quản lý sản phẩm, đơn hàng, khách hàng cho đến thanh toán và vận hành hệ thống.

Không chỉ đơn thuần là một website bán hoa, hệ thống còn hỗ trợ tự động hóa quy trình đặt hàng, quản lý tồn kho, theo dõi trạng thái đơn hàng và chăm sóc khách hàng hiệu quả.

Website được xây dựng với giao diện hiện đại, hiệu ứng mượt mà, tối ưu trải nghiệm người dùng trên cả Desktop và Mobile.

Hệ thống phát triển theo kiến trúc Fullstack hiện đại với Frontend ReactJS và Backend Spring Boot, dễ dàng mở rộng và tùy biến theo nhu cầu thực tế.
